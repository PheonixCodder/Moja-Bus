## 3. Purpose
Configures the internationalization framework (`i18next` and `react-i18next`), loads French and English translation resources, detects device locale, and manages user language persistence.

## 4. Responsibilities
- Initialize `i18next` with `fr.json` and `en.json` bundled dictionaries.
- Default to French (`fr`) as canonical language for Côte d'Ivoire transit operations.
- Persist operator language preference to AsyncStorage key `booth-app-user-locale`.
- Export helper functions: `switchLanguage(locale)` and `getCurrentLanguage()`.

## 5. Dependencies
- `@react-native-async-storage/async-storage`
- `expo-localization` (`getLocales`)
- `i18next` & `react-i18next`
- `@/locales/en.json` & `@/locales/fr.json`

## 11. Logic Audit
- **Startup Hydration**: Lines 30-38 read `AsyncStorage.getItem(USER_LOCALE_STORAGE_KEY)` and call `i18n.changeLanguage(stored)` if present.
- **Device Fallback**: Correctly checks `getLocales()?.[0]?.languageCode` for automatic French selection on francophone West African devices.

## 12. State Management Audit
- **Dual Persistence Hazard**: `i18n.ts` stores locale in `AsyncStorage` under `"booth-app-user-locale"` while `stores/session.ts` also has `locale: SupportedLocale` in Zustand persisted under `"booth-session"`. When `session.setLocale` is called, `switchLanguage` must also be called to prevent desynchronization.

## 13. Async / Side-Effect Audit

## 15. Offline / Synchronization Audit

## 16. Performance Audit

## 20. Reference Comparison
- **`@apps/traveler-app/`**: Traveler app uses identical `i18next` structure and French/English parity test.

## 21. Problems
1. [STATE DUPLICATION] Locale state lives in two stores: `AsyncStorage("booth-app-user-locale")` and `useSessionStore.locale`.
2. [ASYNC HYDRATION RACE] AsyncStorage read at line 30 is un-awaited at module load time; could lead to a single-frame flash if user language is English on a French device.

## 22. Severity
- **Classification**: `P2`
- **Rationale**: Solid core architecture; dual persistence should be unified with `session.ts`.

## 23. Recommended Changes
1. Unify locale storage: ensure `session.ts` and `i18n.ts` share a single synchronized setter.
2. Ensure boot gate in `app/index.tsx` awaits locale restoration if non-default.

## 24. Refactoring Plan
1. Step 1: Keep existing exported methods intact.
2. Step 2: In Phase 4 (Stores), bind `useSessionStore.setLocale` directly to `switchLanguage`.
