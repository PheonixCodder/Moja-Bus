# 04 — Size Bloat & File Hygiene Deep Dive

This document explains why `apps/driver-app` reached over **340 MB** on disk and in archives, while `apps/traveler-app` maintained a lean baseline of **~80 MB** (excluding local node_modules).

---

## 1. Measured Disk Consumption Breakdown

| Directory / Artifact | Size (MB) | Reason for Existence / Problem |
| :--- | :--- | :--- |
| `android/` (.gradle, .kotlin, build) | **111.16 MB** | Compiled build artifacts, Gradle cache, Kotlin intermediates, and prebuild output untracked in `.gitignore`. |
| `test-archive-1/` | **56.71 MB** | A complete duplicate clone of the entire Moja monorepo nested inside `apps/driver-app/` (including its own `.git` history, `.pnpm-store`, apps, packages). |
| `test-archive/` | **0.05 MB** | Leftover temporary test archive. |
| `node_modules/` | **23.61 MB** | Sandboxed local dependency tree. |
| Root source code (`app`, `features`, `lib`) | **0.25 MB** | Actual source code. |

---

## 2. Root Cause Analysis

### Cause 1: Rogue Nested Monorepo (`test-archive-1`)
A previous developer or automated script ran a clone/archive command directly inside `apps/driver-app/` named `test-archive-1`. This directory alone duplicated:
- Full `.git` object tree
- `packages/` directory
- `apps/` directory
- `ivory_coast_data/` and scripts

### Cause 2: Inadequate `.gitignore`
The `.gitignore` in `apps/driver-app` was only 6 lines:
```gitignore
# @generated expo-cli sync-2b81b286409207a5da26e14c78851eb30d8ccbdb
# The following patterns were generated by expo-cli

expo-env.d.ts
# @end expo-cli
```
Because `/android`, `test-archive*`, `dist/`, `.expo/`, and `node_modules/` were not ignored, all generated Gradle caches and cloned files persisted and bloated the project.

---

## 3. Remediation Plan

1. **Delete Rogue Folders**:
   - Remove `apps/driver-app/test-archive-1`
   - Remove `apps/driver-app/test-archive`
2. **Clean Android Build Caches**:
   - Remove `apps/driver-app/android/.gradle`, `apps/driver-app/android/.kotlin`, `apps/driver-app/android/build`
3. **Synchronize `.gitignore`**:
   - Copy the comprehensive 43-line `.gitignore` from `apps/traveler-app` to `apps/driver-app`.
